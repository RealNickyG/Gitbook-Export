# Whalan Planning

NSWRA Hosts a smaller MPR launch opportunity Monthly. The team may be able to take advantage of these for either personal development, small scale testing, system testing and verification, data collection or inductions. These will always occur on a Saturday, unless a public holiday prohibits this, and typically is hosted 9-1pm at Whalan Reserve Sydney.\
Details and dates can change frequently, so make sure NSWRA's site is checked regularly:

### Planning

Because of the early start and location, the team must set out early in the morning, prepared and ready for the day. It is recommended that the team does not plan to stop for breakfast to save on time and not require an even earlier start. If this is the case, make sure this is made clear and done so early so members can have time to prepare and eat prior to attendance.

Make sure to plan what the purpose of the launch day will be, and try to accommodate resources and set expectations accordingly.
